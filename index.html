Fallback para bloqueio de CORS

    
Navegadores só conseguem ler as imagens externas quando o servidor de origem autoriza CORS. Se o teste acusar bloqueio, use o workflow incluído neste repositório. Ele baixa as imagens no servidor do GitHub e cria a mesma branch de revisão.

    
Configure no repositório desta ferramenta o segredo ORATIO_TOKEN e execute a ação Importar imagens do Oratio. O pacote inclui instruções completas no README.
